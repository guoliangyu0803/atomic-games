# 原子物理闯关 · 离线版

四个可以直接在浏览器里玩的原子物理小游戏，**不用联网、不用安装、不用登录**。
适合课堂投屏演示，也适合让学生自己用手机扫码刷题。

- 🔬 **氢原子光谱** — 里德伯公式算波长、5 条谱线归线系、自己在能级图上画跃迁生成光谱
- 🧪 **钠原子光谱** — 电子组态、按真实项值排能级、四大线系、算出 589 nm 的 D 线
- 🧲 **塞曼效应** — 项符号、朗德 g 因子、m_J 列表、m_J·g、9 条允许跃迁与 σ±/π
- 🧭 **原子的磁矩** — 轨道与自旋磁矩、朗德 g 因子合成、μ_J 与 J 不共线的矢量图

全部是纯 HTML + CSS + JavaScript，没有任何外部依赖，断网、无 U 盘权限的机房都能跑。

## 一、最简单的用法：直接双击

双击 `index.html`，用浏览器打开即可。

> 这种方式下只有**这台电脑**能看。适合老师自己投屏演示，不适合让学生各自打开。

支持的浏览器：Chrome / Edge / Firefox / Safari 近几年版本都行。
手机、平板也能直接打开（把整个文件夹拷过去即可）。

## 二、课堂用法：学生扫码进入

1. **双击 `启动课堂服务器.bat`**
   - 会弹出一个黑色窗口，显示两个地址，例如：
     - 本机打开：`http://127.0.0.1:8000/`
     - 学生扫码：`http://192.168.1.10:8000/`
2. 浏览器会自动打开二维码页面，**把这个页面投到大屏**。
3. 学生手机连上**同一个 WiFi**，用相机/微信扫一下，就能在自己的手机上打开合集。
4. 用完直接关掉那个黑色窗口，服务就停了。

### 学生打不开怎么办（按顺序排查）

| 现象 | 原因 | 处理 |
|---|---|---|
| 手机一直转圈 | 电脑防火墙拦了 | 第一次运行时 Windows 会弹「是否允许访问」，选**允许**。若当时点了取消：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾选 Windows PowerShell |
| 手机能开别的网页，但打不开这个 | 手机和电脑不在同一个网络 | 确认连的是同一个 WiFi；有些校园网/访客网络会禁止设备互访，改用手机热点让电脑连手机热点 |
| 二维码页面提示"当前地址是 localhost" | 用了 127.0.0.1 打开 | 用窗口里显示的 `192.168.x.x` 那个地址，或点页面上的「修改地址」手动填 |
| 换了个网络后地址变了 | IP 是自动分配的 | 重新运行 `启动课堂服务器.bat`，页面会显示新地址 |
| 8000 端口被占用 | 别的程序占了 | 脚本会自动往后找端口（8000→8011）。也可以手动指定：`powershell -ExecutionPolicy Bypass -File server.ps1 -Port 9000` |

> 提示：如果只是想在教室大屏上演示，**不需要**开服务器，直接双击 `index.html` 更省事。

## 四、三个游戏分别考什么

### 氢原子光谱（3 关）

| 关卡 | 任务 | 知识点 |
|---|---|---|
| 1 | 填 E₁、E₂ 和 2→1 的波长 | E_n = −13.6/n²，里德伯公式，λ = 1240/ΔE |
| 2 | 把 5 条真实谱线归入线系 | 莱曼/巴尔末/帕邢/布喇开/普丰特，末态决定线系 |
| 3 | 在能级图上画出所有跃迁 | 谱线条数 = n(n−1)/2，线系与波长分布，短波极限 |

第 3 关可以切换 n ≤ 3/4/5/6，画完自动生成光谱图（对数波长轴，带可见光色带）。

### 钠原子光谱（4 关）

| 关卡 | 任务 | 知识点 |
|---|---|---|
| 1 | 选出基态电子组态 | 1s²2s²2p⁶3s¹，单价电子 |
| 2 | 按能量给 6 个能级排序 | 量子数亏损导致 l 简并解除；4S 比 3D 低 |
| 3 | 匹配四大线系 | 主线系/第一辅线系/第二辅线系/柏格曼系 |
| 4 | 画出主线系三条跃迁 | λ = 1/ΔT；算出 589 nm 的 D 线 |

能级用的是**真实项值**（cm⁻¹，以 3S 为 0，电离限 41449.5）：
3S 0、3P 16973、4S 25740、3D 29173、4P 30273、5S 33201、5P 35041。

> 其中 3D 与 4P 真实只差约 1100 cm⁻¹，画面上会重叠，因此略微分开画，页面里有注明。

### 塞曼效应（6 关）

| 关卡 | 任务 | 知识点 |
|---|---|---|
| 1 | 读懂 ³P₂ | 2S+1、L、J 的含义，2J+1 个子能级 |
| 2 | 算两个朗德 g 因子 | g = 1 + [J(J+1)+S(S+1)−L(L+1)]/[2J(J+1)]，得 1.5 和 2 |
| 3 | 算裂成几条 | 5 条、3 条 |
| 4 | 列出 m_J | 2,1,0,−1,−2 与 1,0,−1 |
| 5 | 列出 m_J·g | 3,1.5,0,−1.5,−3 与 2,0,−2 |
| 6 | 连出 9 条允许跃迁 | Δm_J = 0,±1，σ⁺/σ⁻/π 偏振，9 条等间距谱线 |

### 原子的磁矩（4 关）

| 关卡 | 任务 | 知识点 |
|---|---|---|
| 1 | 判断磁矩的来源 | 轨道运动 + 电子自旋两条来路 |
| 2 | 算 μ_L 与 μ_S | √(l(l+1)) 与 g_S√(s(s+1))；g_S ≈ 2 的"反常" |
| 3 | 算 ³P₂ 的 g 与 μ_J | 朗德公式；μ_J = g√(J(J+1))μ_B（**不是** g·J） |
| 4 | 看矢量图判断 μ_J 与 J 的关系 | g_L ≠ g_S 导致 μ_J 不平行于 J，只做进动 |

关键结论：μ_z = −g_J m_J μ_B 取离散值，所以磁场中能量离散——这正是塞曼分裂的根源；
银原子 ²S₁/₂ 只有 μ_z = ±1 μ_B，所以斯特恩-盖拉赫实验里分裂成两束。

## 五、想改内容怎么办

四个游戏都是单文件，用记事本 / VS Code 打开就能改：

- **改题目**：搜 `L1`、`L2_LINES`、`ORDER`、`SERIES`、`UPPER` 这些变量名，数据都集中放在 script 开头。
- **改配色**：每个文件顶部 `:root { ... }` 里改 CSS 变量即可（`--teal` 是主色）。
- **改二维码页文案**：`qr.html` 里的 `.steps` 段落。
- **加新游戏**：复制任意一个游戏文件改名，再到 `index.html` 里加一张卡片。

⚠️ 注意：文件名是中文时，建议保存为 **UTF-8** 编码，否则可能出现乱码。

## 六、学生不在同一个网络怎么办

二维码里现在填的是 `192.168.x.x`，**只有连同一个 WiFi 的手机才能打开**。
如果学生在家、或用的是手机流量，就必须给这个项目一个**公网可达的地址**。三种做法：

### 方案 0：公网隧道（**立刻可用**，不用备案、不用审核、不用注册）

双击 **`启动公网隧道.bat`**，等几秒钟，窗口里会打印一个公网地址，形如：

```
https://81b5d64ae62201.lhr.life
```

把这个地址（或它的二维码）发给学生，**学生用 4G 流量也能直接打开**，不需要和你同一个 WiFi。

原理：Windows 自带的 `ssh` 反向隧道 + localhost.run 免费服务，零安装、零注册、零备案。

**注意**：
- 地址是**临时**的，关掉窗口就失效，下次启动会换成新地址
- 需要你的电脑保持开机、不休眠、不退出那个窗口
- 速度取决于你家里的上行带宽，图片多的页面会稍慢（本项目很轻，一般没问题）
- 如果连不上，换手机热点给电脑联网再试，或改用方案 A/C

### 方案 A：免费静态托管（长期使用，一次上传管一学期）

GitHub Pages / Cloudflare Pages / Netlify 都能免费托管纯静态页面，支持网页拖拽上传，不用写代码。

以 **GitHub Pages** 为例：

1. 登录 GitHub，新建一个 **Public** 仓库，例如 `atomic-games`
2. 进入仓库 → `Add file` → `Upload files` → 把本文件夹里的
   `index.html`、`hydrogen.html`、`sodium.html`、`zeeman.html`、`qr.html`
   （其余文件可传可不传）一起拖进去 → Commit
3. `Settings` → `Pages` → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)` → Save
4. 等 1 分钟左右，访问 `https://<你的用户名>.github.io/atomic-games/`
5. 打开这个地址下的 `qr.html`，二维码会自动指向这个公网网址，投屏让学生扫即可

> ⚠️ 二维码库已经内联进 `qr.html`，所以**不需要额外上传任何子目录**。
> ⚠️ 用 URL 参数也能指定二维码内容：`qr.html?u=https://你的地址/`

### 方案 B：临时公网隧道（不改代码，上课才开）

在能上网的电脑上跑本项目的服务器，再用隧道工具把它映射到公网：

```
cloudflared tunnel --url http://localhost:8000
```

会打印一个 `https://xxxx.trycloudflare.com` 的临时地址，填进 `qr.html` 的「修改地址」就能出二维码。

- 优点：不用部署、不占空间、随开随用
- 缺点：每次地址都会变；电脑必须一直开着；下课就失效

### 方案 C：直接发文件（完全不需要网络）

把 `atomic-games.zip` 发到班级群，学生解压后双击 `index.html` 就能玩。

- 优点：零基础设施，永远可用
- 缺点：手机端操作略麻烦（iOS 要在「文件」App 里选择用浏览器打开）；收不到统一数据

### 现实建议

- **长期作业**：用方案 A，把网址贴在班级群公告里，一次配置管一学期
- **只是课上演示**：方案 B 或直接把手机和电脑连同一个热点
- **网络很差/机房断网**：方案 C，提前把 zip 发下去
- GitHub Pages 在国内偶尔会慢或打不开；学生多、网络不可控时，用学校的教学平台（超星、雨课堂、钉钉、企业微信）上传 zip，或放到学校 Web 服务器上会更稳

## 七、技术说明

- 纯静态：`file://` 双击可用，也可放在任何 Web 服务器 / GitHub Pages 上。
- 无外部请求：不加载 CDN、字体、统计脚本；二维码库是本地文件。
- 服务器用 .NET `TcpListener` 手写的极简 HTTP/1.1，**不需要管理员权限**，也不需要安装 Python/Node。
- `server.ps1` 已存为 UTF-8 with BOM，保证 Windows PowerShell 5.1 下中文不乱码。
- 进度不做持久化（刷新即重来），因为 `file://` 下 localStorage 行为各浏览器不一致。
